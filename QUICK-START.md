# Quick Start

1. Create a ChatGPT Project named **PYQ Intelligence System**.
2. Add `PROJECT-INSTRUCTIONS.txt` to Project instructions.
3. Upload `SKILL.md` and `PYQ-IS-Reference-Manual.md` as reference files.
4. Upload PYQ papers and the applicable syllabus.
5. Ask for the required analysis.
6. Review the proposed execution plan and explicitly approve it.
7. Review the generated reports and quality-assurance issues.

**Approval-first is mandatory:** do not begin bulk processing before approval.

**Syllabus mapping:** use both the uploaded syllabus and official online sources. Pause if versions conflict.

**Supported outputs:** Excel, PDF, Markdown and CSV.

## Start prompt

> Follow the PYQ Intelligence System instructions. I am uploading examination papers and a syllabus. First inventory the documents and propose an execution plan. Do not process the papers until I approve.
