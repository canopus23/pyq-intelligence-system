# Contributing

Contributions that improve clarity, reliability, portability, or examination-analysis quality are welcome.

## Before submitting

- Keep instructions platform-aware; do not claim unsupported capabilities.
- Preserve source traceability and original question wording.
- Do not present fabricated examples as real exam questions or official syllabus data.
- Keep frequency measures and similarity categories clearly defined.
- Update relevant documentation, examples, schema, or acceptance tests alongside changes.
- Never commit exam files containing personal data, credentials, or copyrighted material without permission.

## Suggested workflow

1. Fork the repository and create a focused branch.
2. Make the change and update documentation.
3. Run through `tests/acceptance-tests.md` where applicable.
4. Open a pull request describing the motivation, changes, and validation.
